# Tipos de Issues

Los tipos de Issues son categorías predefinidas que nos ayudan a clasificar y organizar los diferentes Issues dentro de un proyecto. Esto facilita la identificación rápida del tipo de solicitud o problema que se está reportando, lo que a su vez agiliza el proceso de asignación y resolución.

## Tabla de Tipos de Issues

---

La siguiente tabla detalla los tipos de Issues utilizados en los proyectos Open Source:

| Tipo de Issue | Descripción |
|---|---|
| **Mejora de documentación** | Con la solicitud de mejora de documentación puede contribuir agregando o modificando documentación al componente. |
| **Reportar error** | Utiliza esta opción para reportar errores en el componente. |
| **Reportar una vulnerabilidad de seguridad** | Describa claramente la vulnerabilidad de seguridad encontrada. |
| **Solicitud de mejora** | La solicitud de mejora se utiliza para formalizar y documentar propuestas destinadas a mejorar características existentes o proponer nuevas funcionalidades. |

## Procedimiento para la Creación de un Issue

---

Acceder a la sección de Issues dentro del proyecto.
Pulsar el botón "New Issue".
Seleccionar el tipo de Issue que corresponda a la naturaleza de la solicitud o problema.
Pulsar "Get started".
Asignar un título conciso y descriptivo al Issue.
Proporcionar una descripción exhaustiva y clara del problema, solicitud o mejora.
En caso de ser pertinente, asignar el Issue a un miembro específico del equipo.
Pulsar "Submit new issue" para registrar el Issue en el sistema.

1. Navegar a la sección de Issues dentro del repositorio del proyecto.
2. Seleccionar la opción <span class="green label">__*New Issue*__</span>
3. Elegir el tipo de Issue que mejor se alinea con el elemento a registrar. Pulsar <span class="green label">__*Get started*__</span>
4. Proporcionar un título descriptivo y una descripción detallada del Issue, incluyendo toda la información relevante que facilite su comprensión y resolución.
6. Si es necesario, asignar el Issue a un miembro específico del equipo.
7. Confirmar la creación del Issue para que sea visible y accesible para el equipo del proyecto. Pulsar <span class="green label">__*Submit new issue*__</span>

> La gestión efectiva de Issues es fundamental para el éxito de los proyectos Open Source. Al seguir estas pautas y utilizar los tipos de Issues de manera adecuada, contribuimos a una colaboración más eficiente y a la mejora continua de nuestros proyectos.
