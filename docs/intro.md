# Introducción

🖐 ¡Hola bienvenid@ a la comunidad Open Source Bancolombia! 

Aquí encontraras diferentes proyectos de código abierto en los que puedes utilizar y/o contribuir, revisa cual puede ser de tú interés, para que puedas participar activamente en nuestra comunidad. 👨‍💻

Queremos brindarte toda la información para hacer tu viaje lo más claro posible, por eso hemos habilitado una detallada documentación y algunos lineamientos que deberás cumplir para que esta comunidad funcione de manera armónica y clara. 🚀

¡Gracias por llegar a nuestra comunidad! ¡Esperamos que esto sea el inicio de una grata experiencia! 💖🌟

Si a lo largo de tu camino requieres apoyo no dudes en contactarnos al siguiente correo:

👉 opensource@bancolombia.com.co

y sin más preámbulos iniciemos este viaje Open Source Bancolombia...
